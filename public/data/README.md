# 夜市初始資料

`night-markets.json` 的來源是經濟部商業發展署在政府資料開放平臺發布的[夜市資料（95760）](https://data.gov.tw/dataset/95760)。原始 CSV 資源網址與匯入日期保存在 JSON `metadata`。

官方資料平台 modal 顯示品質平台在 2026-09-18 08:47:32 有 75 筆非即時快照；本地已匯入 JSON，清除 2 筆空白列後保留 73 筆候選，並與人工確認資料合併去重為 86 筆。候選資料保留序號、快照日期與品質平台 URL，介面標示為「待複核」，不代表官方最新或完整全台名錄。中壢觀光夜市與中原夜市另保留官方觀光頁 URL；座標是 OSM 入口或商圈中心近似點，逐筆以 `coordinateSource` 與 `coordinatePrecision` 標示，未核對欄位保持空白。
